# X7 Pro 0.9.0：完整画幅与处理性能

本版在 PenOS 4.34.0 的 X7 Pro 上安装并运行。先安装此前未上机的 0.8.1，再进行本版的设备能力查询、对照拍摄与安装。没有改动启动链、ADB 持久化、CPU 调频策略、驱动绑定或系统相机服务。

## 照片与对焦

- 只读查询 V4L2 后，确认当前输出节点支持 3264×2448 NV12。相机会话使用完整画幅，退出时恢复打开前的格式和裁切。4:3 提升到 3264×2448，正方形提升到 2448×2448；其他照片比例保持原尺寸。提高输出尺寸和视野不代表镜头实际解析力同比增加。
- 保留系统 RKAIQ 连续对焦，不直接驱动镜头。拍摄前结合只读镜头位置、清晰度变化、画面运动与亮度判断等待时间。最近的稳定结果只有在镜头与当前场景重新核验后才能复用；场景变化会失效。电机稳定和算法分数都不能证明光学对焦准确。
- 普通拍照按场景在一帧或三帧新图像中选择；三帧按清晰度和运动评分择优，移动场景优先当前画面。只保留一张候选原图，避免建立多张 8MP 缓冲。连拍后续帧可走单帧路径。这不是多帧融合或超分辨率。
- 原有亮度降噪、阈值锐化和暗光质量模式改用 ARM NEON；与标量参考逐像素对照。原尺寸 NV12 色度分离也使用 NEON，奇数裁切行保留原先插值规则。自然色和黑白预览按需分配缓冲，省去未使用的 RGB 内存。

## 相册和录像

- 进入相册先关闭实时相机，避免后台取景与缩略图解码、视频播放争用资源；返回时重新打开并恢复取景。保留 0.8.1 的缩略图缓存、滚动窗口、自动方向修复和完整视频帧快照。
- 录像仍为 MJPEG/PCM AVI，支持省空间、720p 和 1080p。视频目标帧率仍为 30/30/24，实际速度取决于方向、滤镜、场景和设备负载。没有将预览轮询速度当作屏幕实际呈现帧率。
- 原厂相册索引、前台扫描拦截、方向与自拍行为保持原有流程；不改变用户已有偏好。

## 资源实验与取舍

实机查询到 RGA2 Enhance 和 Mali-G52 OpenCL，并用独立程序完成缩放、旋转、DMA 缓冲和图像降噪实验。实验代码位于 `tools/experiments`，没有链接进发行模块。结果包含传输成本，不只计核函数执行时间。

NEON 的 720p 亮度质量降噪约 30.61 → 10.61 ms，输出与标量实现一致。GPU 在部分大图上较快，但在 720p 和并行相机负载下没有稳定的整体收益，因此本版默认使用 CPU/NEON。RGA 转换的传输与缓存开销也需要算入全链路，未仅因硬件可调用就启用。原始数据见 `evidence/resources-0.9.0.json`。

接口依据为 [Rockchip librga 固定版本头文件](https://github.com/airockchip/librga/tree/97bff5e9c49d6ec2edfb245993cc77425db85bea/include)、[Khronos OpenCL-Headers](https://github.com/KhronosGroup/OpenCL-Headers) 和 [Rockchip 5.10 DRM UAPI](https://github.com/rockchip-linux/kernel/blob/develop-5.10/include/uapi/drm/rockchip_drm.h)。复制的公共头文件附有来源和许可。当前内核编码能力检查没有发现可用的 H.264 编码器，本版继续使用已验证的 TurboJPEG。

## 验证与限制

- 81 项 JS 自动检查；原生标量/NEON 一致性、缓冲边界、旋转、噪点与边缘、AF 策略、完整播放快照检查。原生检查显式取消 `NDEBUG`，保证优化构建仍执行断言，并在 Windows 和真实 ARM 设备上运行。
- 设备对照测试见 `evidence/optimization-0.9.0.json`：同一设备、场景、亮屏与系统频率条件，两版保存同尺寸 16:9 照片，记录对焦等待、原图选择、处理与保存时间。它是本次样本，不代表所有场景。
- 六种照片比例、八种滤镜、EXIF、变焦、竖屏、全文件解码与相机重开见 `evidence/profiles-filters-time-0.9.0.json`；录像矩阵、音轨、限额收尾和麦克风恢复见 `evidence/hd-validation-0.9.0.json`。
- 自动检查只删除各自创建的媒体。安装后核对设备字节码、原生 ELF 代码数据段与构建产物，并确认已有偏好保持。
- 用户不在设备旁，没有要求手持旋转、标准对焦标板或实际暗光拍摄；因此未确认这些场景的主观画质。软件提亮不能恢复传感器未记录的细节。局域网下载按先前要求跳过。
