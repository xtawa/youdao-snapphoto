# 0.9.3：修复退出后再次打开黑屏

设备日志明确记录 `ReferenceError: could not load module filename photoAlbum`，随后页面生命周期对象为空，导致整个页面无法启动。

原生模块会保留原厂相册库的 dlopen 句柄，但固件在应用销毁时清空其模块注册。原实现发现已有句柄便提前返回，二次打开时跳过了注册。现在继续复用原厂库，同时在每次应用启动时重新调用其注册入口。没有修改或替换原厂相册文件。

0.9.3 保留快拍、内置 FFDNet NPU 模型、后台队列和现有设置。修复仅涉及模块启动生命周期，没有调整相机参数、对焦、系统电源或 ADB。

验证：100 项 JS 检查通过；实际 MiniApp 宿主进程不重启，连续三次退出、等待原生卸载、重新打开并进入相册。每轮均确认启动生命周期成功、预览文件持续更新、没有模块导入错误。证据为 `evidence/relaunch-0.9.3.json`，截图仅留在私有目录，不随源码分发。此前 0.9.2 的 NPU/快拍性能记录作为继承证据保留，不宣称本次重复了全部性能测试。
